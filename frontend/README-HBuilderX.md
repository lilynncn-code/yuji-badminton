## 安卓真机提示版本不兼容

如果 HBuilderX 连接安卓手机真机调试时提示“版本不兼容”，优先按下面顺序处理：

1. 请使用 HBuilderX 4.76 打开本目录，然后完全退出 HBuilderX 再重新打开一次。
2. 先尝试更新调试应用并重新连接。卸载会删除本机数据，请先备份；不要为了排查问题直接卸载正在使用的好羽。只有确认数据已保存且确有需要时，再重装临时调试应用。
3. 确认 HBuilderX 打开的是本目录 `frontend`，不要打开外层 `App-好羽`。
4. 如果你用的不是 HBuilderX 4.76，就二选一：要么换成 4.76，要么把 `package.json` 里的全部 `@dcloudio/*` 依赖换成你当前 HBuilderX 自带的同一批版本，然后删除 `node_modules` 和 `package-lock.json` 后重新安装。

当前项目依赖已经对齐这台电脑 HBuilderX 自带的 `3.0.0-alpha-4070620250722001` 这一批，生成时会显示 `Compiler version: 4.76`。如果以后升级 HBuilderX，再把 `package.json` 里的 `@dcloudio/*` 依赖一起升级到新 HBuilderX 对应版本。

AI 识别页在安卓真机上使用 `manifest.json` 里的 `livepusher` 能力打开实时摄像头预览。HBuilderX 图形界面里如果看到 App 模块没有勾选 LivePusher，请重新读取 `manifest.json` 后再运行到手机。

## 后端地址

前端请求后端的地址统一在这里：

```text
frontend/utils/auth.js
```

当前真机调试地址是固定写在代码里的值，不会自动跟随 Wi-Fi 变化：

```text
http://192.168.0.104:8000
```

电脑浏览器运行前端时，会自动用浏览器当前打开的电脑地址去连 `8000` 端口。例如前端页面是：

```text
http://192.168.0.104:5173
```

那么前端会请求：

```text
http://192.168.0.104:8000
```

手机连接电脑后端时，不要使用 `127.0.0.1`。手机里的 `127.0.0.1` 是手机自己，不是电脑。

先启动后端：

```bash
cd "./backend"
chmod +x run-local.sh
./run-local.sh
```

看到后端启动后，在手机浏览器打开下面地址测试：

```text
http://192.168.0.104:8000/health
```

如果能看到 `{"status":"ok"}`，只说明手机浏览器能访问这个地址。仍需在 App 中检查登录、上传和其他请求。

如果电脑 Wi-Fi 地址变了，运行下面命令查看新地址：

```bash
ipconfig getifaddr en0
```

然后改 `frontend/utils/auth.js` 里的这一行：

```js
const LOCAL_BACKEND_HOST = '192.168.0.104'
```

需要填写的真实网址是正式后端的公网地址，也就是手机和用户都能访问到的后端地址，例如：

```text
https://api.example.com
```
